# 💱 Currency Converter Web App

A responsive and user-friendly Currency Converter Web App built using HTML, CSS, JavaScript, and Exchange Rate API for real-time currency conversion.

🌐 Live Demo: https://real-currencyconverter.netlify.app/

## 🚀 Features
- Real-time currency conversion  
- Clean and responsive UI  
- Multiple currency support  
- Fast and simple user experience  

## 🛠️ Tech Stack
- HTML5  
- CSS3  
- JavaScript  
- Exchange Rate API  
- Netlify
